# Hanover fonts

Polices Hanover des familles EUROFONTS et POLICES, incluant les polices pour les fonds de couleurs et des fonds de base pour les girouettes de toutes tailles.

Ces polices sont conçues de sorte que les points aient tous la même taille.

Note : Pour la police "Hanover Colour RN", certaines déclinaisons avec la diagonale ne sont pas correctes. Elles seront corrigées dans une version future.

## Fonctionnement

__**Note générale**__ : Le nombre sur le nom des polices correspond à la hauteur maximale de la police. De plus, essayez au maximum que la taille des cercles correspondent entre toutes les polices, n'utilisez pas la mauvaise police.

### Girouette sans couleur

1. Allez dans le dossier `signes_background/` puis sélectionnez un dossier. Le dossiers le plus utilisé est `externally_viewed_mono_led_signs`
2. Une fois une variante choisie, allez dans le dossier `backgrounds/_guide` et ouvrez une image dans le logiciel de votre choix.
3. Il est conseillé de commencer par l'indice de ligne. Prenez la police de votre choix et aggrandissez sa taille jusqu'à ce que les points de la police correspondent avec les points du fond.
4. Une fois l'indice de ligne posé, dupliquez le texte et choisissez une autre police sans changer la taille du texte. Il est important de conserver la même taille des points sur toute la girouette.

### Girouette avec couleurs

1. Allez dans le dossier `signes_background/` puis sélectionnez un dossier. Le dossier le plus utilisé est `color_rn_multicolour_route_number_signs`
2. Une fois une variante choisie, allez dans le dossier `backgrounds/_guide` et ouvrez une image dans le logiciel de votre choix.
3. Il est conseillé de commencer par l'indice de ligne. Pour obtenir le fond de l'indice de ligne, utilisez la police "Hanover Colour RN", puis sélectionnez la variante correspondant à la taille de la girouette. Tapez la lettre "a" pour un fond normal, ou la lettre "b" pour un fond avec une diagonale.
4. Dupliquez ensuite le texte et choisissez une autre police sans changer la taille du texte. Il est important de conserver la même taille des points sur toute la girouette.

Pour obtenir un effet contour sur le texte :
- Mettez le texte en gras. Si cela ne fonctionne pas, sélectionnez manuellement la version "Bold" de la police.
- Tapez le texte souhaité en noir ou dans une autre couleur.
- Dupliquez ce texte et utilisez la version "Regular" (version de base) avec la couleur souhaitée.

## Caractères spéciaux

### Police RER
- Signe RER : r
- Signe B : B

### Police Roissybus
- Signe Roissybus : A

### Polices Parisine
- Signe Métro : #
- Signe Tramway : $
- Signe RER : +
- L'apostrophe : '
- Point central : •

### Police HanRPF22
- Signe Métro : #
